HTML(HyperText Markup Language)
- 페이지를 이동, 태그로 구성된 언어
- markup: `<tagname> ... </tagname>`
  - tag: 문서의 데이터가 어떤 역할(제목, 본문 등)을 하는지 표시하는 언어
- Structure: HTML
- Styling: CSS(Cascading Style Sheet)
  - Cascading: 상위요소 스타일이 하위요소 스타일에 전달
- Dynamic element: JavaScript
- 확장자: html/htm

---
HTML
- 웹표준(web standard): 어떤 브라우저를 사용해도 동일 화면, 동일 기능
- 기본 구성(항상 정해진 4가지 필수 태그):
```
<!Doctype html> => HTML version 인식하는 태그 "HTML5 버전으로 현재 문서가 작성됨"

<html> => 문서의 시작

    <head>...</head> => 문서의 정보, 문서 자원(확장자-css, js)에 대한 정의
    <body>...</body> => 문서에서 출력되는 부분
    
</html> => 문서의 종료
```

- tag (문서의 구조와 관련성이 높다)
  - 1. 제목 태그 (Heading)
    - `<h1>` ~ `<h6>`
    - `<h1>`: 주제목

  - 2. 본문 서식 태그
    - `<p> ~ </p>` 문단 태그
    - `<b> ~ </b>` bold
      - `<strong> ~ </strong>`
    - `<i> ~ </i>` 기울임체
    - `<u> ~ </u>` 밑줄
    - `<del> ~ </del>` 취소선
      - `<strike> ~ </strike>`
    - `<br>`

  - 4. 주석
    - 1. 설명
    - 2. 출력 배제
    - 3. `<!--` 설명/출력 배제할 코드 `-->`

  - 5. 문단 태그(Block 속성)
  - 6. 글 태그 (Inline 속성)

#### Block vs. Inline
줄개행을 하냐 안 하냐 차이가 중요

- **Block**: 줄개행 O, 하나의 큰 영역/묶음으로 사용
  - 기본적으로 한 줄 전체 너비를 차지
  - `width`, `height` 지정 가능
  - `<h1>` ~ `<h6>`
  - `<p>`
  - `<div>`
  - `<ul>`
  - `<li>`

- **Inline**: 줄개행 X, 문장 일부분을 꾸밀 때 사용
  - **내용(content)만큼의 공간만 차지**
  - 일반적으로 `width`, `height`를 직접 지정할 수 없음
  - `<span>`: apply style on a part of text
  - `<strong>`: bold
  - `<em>`: italic
  - `<a>`: hyperlink / page 이동
  - `<img>`: inline 요소이지만 `width`, `height` 지정 가능
  - `<mark>`: apply yellow highlight
  - `<u>`: underline

#### `<div>` 특징

- `<div>` = **division**
- 여러 HTML 요소를 하나의 **영역 / 그룹**으로 묶는 **container**
- **Block 요소**
  - 기본적으로 새 줄에서 시작
  - 한 줄 전체 너비를 차지
- 여러 요소를 `<div>`로 감싸면 하나의 영역처럼 관리할 수 있음
- CSS를 사용해서 해당 영역에 스타일이나 레이아웃을 적용할 때 자주 사용
- `<div>` 자체에는 특별한 의미가 없고, **요소들을 묶는 용도**로 사용

```html
<div>
  <h2>Profile</h2>
  <p>AI Engineer를 공부하고 있습니다.</p>
  <a href="#">GitHub</a>
</div>
```

→ `<h2>`, `<p>`, `<a>`를 하나의 `Profile` 영역으로 묶음

```css
<style>
  div {
  background-color: lightgray;
  padding: 20px;
  } 
</style>
```

→ `<div>`로 감싼 전체 영역에 배경색과 여백을 한 번에 적용 가능

**정리:**  
`<div>` = 여러 HTML 요소를 하나의 **박스 / 영역으로 묶어서 관리하기 위한 Block container**
