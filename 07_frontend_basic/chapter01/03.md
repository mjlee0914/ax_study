[Semantic Tag] - 01-7.html 참고
- Semantic Tag: 의미를 가지고 있는 태그(태그 이름만 보고도 무슨 기능의 태그인지 알 수 있음)  ex) `<form>` `<table>` `<video>`
  - 필요이유:
    - 검색엔진 최적화
    - 웹 접근성
    - 개발자 시각에서 코드 가독성 좋아짐
      - 레이아웃 구성 태그 = **inside `<body>`!!!!**
      - `<header>` 상단 공통영역
      - `<nav>` 메뉴바
      - `<main>` 본문
      - `<section>` 내용 구분
      - `<article>` 내용
      - `<aside>` 왼쪽/오른쪽 영역, 사이드바/광고
      - `<footer>` 하단 공통영역
    
- Non-semantic Tag: 단순히 CSS 스타일 적용하려고 묶어주는 역할
  - ex) `<div>` `<span>`
